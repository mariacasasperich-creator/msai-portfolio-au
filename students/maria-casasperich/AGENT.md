## The loop
Read → judge → choose one thing → change → look again → decide.

## Stopping rule

The first run used "Stop when the page is good." That rule has no test, so it was replaced
after one pass with this one:

- **Bar:** all 5 checks in `RUBRIC.md` pass, each with quoted evidence.
- **Budget:** at most 3 passes of the loop.
- **Plateau:** stop early if one pass does not flip any failing check from fail to pass.
- If the budget or the plateau is reached before the bar is met, stop anyway and say, in the
  pull request, exactly which checks still fail. Do not hide a failure to look finished.
